# Один проект в нескольких агентских средах

Codex — основной путь ИИскры. Hermes и DSH можно подключить к тому же проекту.
Claude Code использует ссылочный CLAUDE.md. Выбор клиента не определяет формат
1С-проекта и доступность MCP.

## Codex

Откройте нужный рабочий каталог в Codex. Корневой AGENTS.md задаёт общее ядро,
более близкая к рабочему каталогу инструкция уточняет проектные условия.
Учитывайте AGENTS.override.md, если такой файл существует. Настройки загрузки
и стандартный общий предел 32 КиБ описаны в официальной документации. Большие
справочники ИИскры подключаются по задаче через чтение файлов.
[Порядок загрузки AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

После изменения инструкции начните новый запуск или сессию и проверьте цепочку.
Попросите агента прочитать текущий AGENTS.md, назвать применимые проектные файлы,
выбранный профиль и запретную цель. Сверьте ответ с содержимым файлов. Доступ
к файлу подтверждает возможность чтения, соблюдение проверяется сценарием стенда.

## Hermes и другие клиенты

Если клиент не подтвердил автоматическую загрузку AGENTS.md, передайте явную
стартовую инструкцию.

```text
Прочитай AGENTS.md из корня этого проекта и обязательные файлы по его списку.
Назови профиль применения, формат исходников и разрешённую цель проверки.
Первый шаг — анализ без правок. Если файл недоступен, сообщи об этом.
```

Проверьте действие инструкции на [первой приёмке](../стенд/приемка-1-анализ.md).
Наличие файла на диске само по себе не подтверждает его загрузку клиентом.
Pi также можно испытать этим способом после установки клиента. Живая проверка
Hermes и Pi в этом выпуске остаётся за пользователем.

## DSH и владелец AGENTS.md

У DSH-плагина 1CProjectProperties есть собственный механизм развёртывания правил.
Он может заменить корневой AGENTS.md. До включения или обновления выберите
владельца корневого файла и сохраните diff пользовательских инструкций.

В проверенной версии 0.15.6 при одновременном наличии AGENTS.md и USER-RULES.md
прежний AGENTS сохраняется в резервную копию, но его текст не добавляется в
уже существующий USER-RULES.md. При этом журнал сообщает об объединении.
После миграции сравните активные файлы и резервную копию по содержимому.
[Исследованный исходник](https://github.com/Mempemp/DSH-1CProjectProperties/tree/1fe110176cfe8e28c4ab4b080296ceb3c6298787)

Выберите один способ подключения.

- **Корневой файл ведёт проект.** Сохраните AGENTS.md ИИскры и подключайте
  необходимые материалы DSH явно. Поведение развёртывания уточните в своей версии.
- **Корневой файл ведёт DSH.** В поддерживаемом пользовательском файле DSH
  разместите инструкцию чтения канона ИИскры из отдельного каталога.
  После развёртывания проверьте, что ссылка сохранилась и файлы действительно читаются.

Автоматическое объединение разных наборов правил здесь не выполняется.
Конфликт требований разрешает владелец проекта до изменения кода.

## Claude Code

Сохраните CLAUDE.md со ссылкой на AGENTS.md. Редактируйте канон в одном месте.
В существующем проекте сначала прочитайте его инструкции, затем объедините
требования с сохранением проектных ограничений. Прежний путь шаблона
`templates/CLAUDE-проекта.md` сохраняется для совместимости.

## Приёмка подключения

1. Прочитать фактическую цепочку инструкций и выбрать профиль.
2. Подтвердить Git/Python и самотесты набора.
3. Для нужного инструмента проверить состояния «настроен / виден / проверен».
4. Пройти анализ без правок и небольшой согласованный цикл на стенде.
5. Зафиксировать версии, результат и ограничения в паспорте проекта.
