# Справочник инструментов

Точные адреса всего, на что ссылаются сценарии установки и страницы набора.
Срез на 2026-08-20; актуальность адресов не гарантируется — проекты живые.

## Контур разработки

| Инструмент | Что это и когда возьмёшь | Адрес |
|---|---|---|
| 1С:EDT | Среда разработки; основа контура | Портал 1С (releases.1c.ru), нужен логин ИТС |
| codepilot1c (форк) | MCP-доступ агента к EDT: наш рабочий вариант с дополнительными операциями и защитами; ставится готовым выпуском | https://github.com/andromanpro/codepilot1c-edt — раздел Releases |
| codepilot1c (исходный проект) | Апстрим форка; наши исправления уезжают туда PR-ами | https://github.com/ondysss/codepilot1c-edt |

## Линия проверки кода

| Инструмент | Что это и когда возьмёшь | Адрес |
|---|---|---|
| BSL Language Server | Анализатор исходников 1С; обязательный минимум линии | https://github.com/1c-syntax/bsl-language-server — Releases, файл `*-exec.jar` |
| SonarQube + модуль BSL | Анализ с историей и порогом качества; когда дозрели до постоянного контроля | https://www.sonarsource.com/products/sonarqube/ + https://github.com/1c-syntax/sonar-bsl-plugin-community |
