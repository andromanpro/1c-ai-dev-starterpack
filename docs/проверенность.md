# Проверки и границы изменения Start/Pro

Дата 09.11.2026. Локальная среда — Windows, Python 3.14.10.
Базовая ревизия — `6c2f94088a3358d9adf295cf09937a43992742dc`.
Точные снимки исходников проверок связаны с SHA256 в квитанциях изображений.

## Воспроизведение

Из корня Git-клона выполните команды. Составы упаковываются в новый каталог.

```bash
py -3 tools/validate.py --selftest
py -3 tools/validate.py
py -3 стенд/проверка-стенда.py --selftest
py -3 tools/build_editions.py --selftest
py -3 tools/build_editions.py --output _downloads/editions
```

Перед публикацией владельцем дополнительно используются `--require-deny`
и проверка сообщений коммитов по диапазону публикуемых изменений.
Приватный словарь хранится за пределами репозитория.

## Область проверки

| Область | Проверка | Граница результата |
|---|---|---|
| Публичная чистота | Валидатор, его грязная и чистая пробы | Текстовые классы утечек и локальные ссылки |
| Учебный стенд | Дефектный модуль и обманка отклонены, встроенный эталон принят | Эвристика по исходнику, исполнение BSL не проверяется |
| Упаковка | 15 тестов, положительные и отрицательные случаи | Составы, ссылки, квитанции, пути, секреты и сохранение существующего результата |
| Два архива | Отдельная сборка Start и Pro, общие файлы из одного снимка | Пакеты документации и контрольных точек |
| Документация | Проверка ссылок, орфография и визуальный просмотр | Текущая редакция материалов |
| Схемы | Рендер Mermaid в SVG и визуальный просмотр | Подписи, связи и читаемость |

Исходный вывод реальных запусков сохранён в
[квитанции стенда](../assets/stand-check.json) и
[квитанции самотестов](../assets/editions-check.json).
Отрицательная проба упаковщика проверяет и вторую поставку — ссылку Pro на
существующий в клоне, но исключённый из архива файл. Отключение этой проверки
приводит к ожидаемому падению соответствующего теста.

не выполнялись. Независимые аудиты Астры и Kimi использованы для выбора архитектуры.
Их находки сверялись с исходниками, частные пакеты аудита в поставку не включены.
