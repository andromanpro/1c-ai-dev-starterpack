# Вики набора — начать здесь

Короткий маршрут для нового читателя. 1С вы знаете; здесь — как работать с ИИ.

## Маршрут

1. **Прочитайте [быстрый старт](быстрый-старт.md)** — приёмка вашего контура
   двумя прогонами на стенде: 15 минут и час-полтора. Без установки EDT.
2. **Поставьте полный контур агентом** — скажите агенту «настрой окружение»,
   он поведёт по сценариям `../install/`. Что происходит и зачем — на странице
   [контур разработки](контур-разработки.md).
3. **Работайте по циклу** — правила уже подключены через `CLAUDE.md`/`AGENTS.md`;
   что-то пошло не так — [если не получается](если-не-получается.md).
