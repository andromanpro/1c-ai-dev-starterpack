# Если не получается: отказы настройки и первых шагов

Формат: симптом → вероятная причина → что делать. Если вашего случая нет —
дайте агенту дословный текст ошибки и эту страницу; догадки хуже диагностики.

## Агент ведёт себя так, будто правил не существует

- **Причина:** точка входа не прочитана — файл не в корне рабочего каталога,
  либо агент открыт не в том каталоге.
- **Что делать:** проверьте, что агентская среда открыта в каталоге, где лежит
  `CLAUDE.md`/`AGENTS.md`; спросите агента «какие файлы правил ты прочитал?» —
  он должен перечислить четыре файла ядра.

## `py` не найден / python не запускается

- **Причина:** Python не установлен или установлен без запускальщика `py`.
- **Что делать:** поставить Python 3 с python.org (галочка «Add to PATH»).
  Проверка: `py -3 --version`.

## Кириллица в выводе превращается в кракозябры

- **Причина:** консоль Windows в системной кодировке, а файлы набора — UTF-8.
- **Что делать:** это косметика, работе скриптов не мешает — они настраивают
  кодировку сами. Если пишете свой скрипт — первой строкой
  `sys.stdout.reconfigure(encoding="utf-8")`.

## Контрольная точка приёмки 2 не становится зелёной

- **Причина:** исправление не соответствует требованию прогона (например,
  поиск оставлен в цикле «с кешем»).
- **Что делать:** перечитайте требования в приёмке — они намеренно жёсткие;
  попросите агента показать, ЧТО именно он поменял (разницу файла), а не
  пересказ.

## MCP не подключился (сценарий 01, шаг 6 падает)

- **Причина 1:** EDT не запущен — сервер codepilot живёт внутри EDT.
  Запустите EDT, повторите вызов.
- **Причина 2:** агентская среда запущена раньше EDT и не переподключилась.
  Перезапустите агентскую среду после старта EDT.
- **Причина 3:** порт занят или изменён в настройках плагина. Сверьте порт
  в настройках codepilot внутри EDT с портом в конфигурации MCP.

## EDT не находится или старой версии

- **Причина:** установлен только Конфигуратор, или EDT старше 2025.2.
- **Что делать:** EDT ставится отдельно с портала 1С (нужен логин ИТС) —
  это шаг человека, агент не может сделать его за вас.

## Агент «завис» на долгой операции

- **Что делать:** не прерывайте установку на середине без нужды; спросите
  в чате «что ты сейчас делаешь?». Прервали — начните сценарий с его
  проверки предусловий, шаги идемпотентны.
