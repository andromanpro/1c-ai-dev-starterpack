# Быстрый старт: приёмка контура за два прогона

Минимальная дорожка. EDT и полный контур НЕ нужны — только агентская среда
и этот набор. Вы не проходите курс — вы **принимаете в эксплуатацию** свою
связку «агент + правила + машинная проверка» на стенде, двумя приёмочными
прогонами: ~15 минут и ~60–90 минут.

## Что нужно

- Агентская среда — та, что умеет читать и править файлы проекта (см. таблицу ниже).
  Установка — по официальной документации самой среды; понадобится подписка или ключ.
  Дублировать её инструкцию здесь смысла нет: она меняется чаще этого набора.
- Git и Python 3.10 или новее. Команды ниже даны для Windows (`py -3`);
  на Linux/macOS замените на `python3`.
- Клон этого набора.

## Какую среду брать

Набор работает там, где агент видит файлы проекта: он читает правила из `rules/`,
открывает модуль стенда, показывает разницу правок. Это отсекает чат-приложения,
даже очень хорошие.

| Среда | Годится | Что учесть |
|---|---|---|
| Codex, приложение или CLI | основной путь | читает AGENTS.md, затем обязательные файлы по его списку |
| Claude Code | совместимый путь | CLAUDE.md направляет к общему AGENTS.md, прежние прогоны набора выполнялись в Claude Code |
| Hermes и DSH | дополнительный путь | явно подключите инструкцию, проверьте её загрузку и владельца AGENTS.md |
| Cursor и другие с поддержкой MCP | да | правила подключаются файлом инструкции проекта |
| Claude Desktop | да — через встроенный режим Claude Code (агент) | в обычном окне чата файлы проекта не видны; откройте в приложении режим агента и укажите каталог набора |

Частая ошибка первого дня — вставить README в обычное окно чата и решить, что
набор не работает: чат перескажет текст, но не прочитает ни правила, ни модуль
стенда. Нужен именно режим агента. Проверить просто: попросите агента показать
первые строки `rules/01-безопасность.md`. Не смог — вы в окне чата, а не в агенте.

## Приёмка 1 (~15 минут): агент анализирует и не трогает код

1. Склонируйте набор, откройте агентскую среду в каталоге набора.
2. **Оставьте профиль Start** и выберите способность модели в AGENTS.md.
   Если не уверены, используйте профиль слабой модели. CLAUDE.md ссылается
   на общий канон. Порядок подключения других клиентов описан в
   [инструкции клиентов](клиенты.md).
3. Агент прочитает точку входа и правила сам — в них уже включён безопасный
   режим: первая задача — анализ, правки только с подтверждением. Сомневаетесь,
   что подключилось, — скажите **«проверь контур»**: агент прогонит диагностику
   без правок и покажет таблицу «что живо, что нет».
4. Разыграйте рабочую ситуацию из [../стенд/приемка-1-анализ.md](../стенд/приемка-1-анализ.md):
   «код коллеги, разберись». Сверьте поведение агента с ожидаемым — оно описано
   там же, вместе с приёмом дожима.

Принимаете не знание — поведение: агент читает правила из файла и не лезет
править без спроса.

## Приёмка 2 (~60–90 минут): рабочий цикл с контрольной точкой

[../стенд/приемка-2-цикл.md](../стенд/приемка-2-цикл.md): три дефекта, полный цикл
«анализ → согласование → правка → машинная проверка → приёмка». Ключевой момент:
до правки контрольная точка красная, после — зелёная.
**Слову «готово» не верим — верим точке, сменившей цвет.**

## Дальше

- Полный контур (EDT + codepilot + линии проверки и тестирования) — скажите
  агенту «настрой окружение», сценарии `../install/` он исполнит сам,
  вам останутся установщики и подтверждения. Теория —
  [контур-разработки.md](контур-разработки.md).
- Свой проект — скопируйте `../templates/CLAUDE-проекта.md` в его корень
  и заполните пометки.
