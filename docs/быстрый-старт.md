# Быстрый старт: агент за 15 минут, проверенное изменение за 90

Минимальная дорожка. EDT и полный контур НЕ нужны — только агентская среда
и этот набор.

## Что нужно

- Агентская среда: Claude Code или Codex CLI (установка — по официальной
  документации среды; понадобится подписка или ключ).
- Git и Python 3 на машине.
- Клон этого набора.

## 15 минут: первая задача

1. Склонируйте набор, откройте агентскую среду в каталоге набора.
2. Агент прочитает точку входа (`CLAUDE.md` / `AGENTS.md`) и правила сам —
   в них уже включён безопасный режим: первая задача — анализ, правки только
   с подтверждением.
3. Дайте первое задание из учебного проекта —
   [../учебный-проект/задание-1-анализ.md](../учебный-проект/задание-1-анализ.md):
   «прочитай модуль и расскажи». Сверьте ответ агента с эталоном в задании.

Смысл шага: вы видите, что агент читает правила, анализирует код и не лезет
править без спроса.

## 90 минут: первое проверенное изменение

Задание 2 — [../учебный-проект/задание-2-исправление.md](../учебный-проект/задание-2-исправление.md):
три дефекта, полный цикл «анализ → согласование → правка → машинная проверка →
приёмка». Ключевой момент: до правки контрольная точка красная, после — зелёная.
**Слову «готово» не верим — верим точке, сменившей цвет.**

## Дальше

- Полный контур (EDT + codepilot + линии проверки и тестирования) — скажите
  агенту «настрой окружение», сценарии `../install/` он исполнит сам,
  вам останутся установщики и подтверждения. Теория —
  [контур-разработки.md](контур-разработки.md).
- Свой проект — скопируйте `../templates/CLAUDE-проекта.md` в его корень
  и заполните пометки.
