# Правила написания кода 1С:Предприятие

> **Подключаемый справочник** набора практик: в обязательное ядро не входит.
> Агент читает его по указанию человека или при работе с задачами этого класса.

> Платформа 8.3.27, БСП 3.1. Источники: v8std.ru, CodeStyle1C.

---

## 1. Стиль и качество кода

### Общие принципы
- ✅ **Самодокументируемый код** — избегай очевидных комментариев
- ✅ **Читаемость важнее краткости**
- ✅ **Ограничение строки:** 120 символов
- ❌ **Не используй венгерскую нотацию:** `МассивКонтрагентов` → `Контрагенты`
- ❌ **Не используй тернарные операторы:** `?(Условие, Значение1, Значение2)`
- ❌ **Не используй зарезервированные / глобальные имена для СВОИХ идентификаторов** (переменных, процедур, функций, параметров, **команд форм**). Правило: любое своё имя — префиксное/описательное (`НайтиОстаток`, `КомандаПоиск`, `ллл_Найти`), не голое общее слово — тогда коллизий нет по построению. Нельзя как имя:
  - **глобальные объекты:** `Документы`, `Справочники`, `Метаданные`, `Пользователи`, `Константы`, `РегистрыСведений`…;
  - **ключевые слова:** `Если`/`Для`/`Цикл`/`Пока`/`Функция`/`Процедура`/`Новый`/`Возврат`/`Прервать`/`Выполнить`/`Вычислить`… — переменная-ключевое слово даёт ложную **«Ожидается КонецЦикла/КонецПроцедуры»** на структурно закрытой строке;
  - **глобальные функции и методы коллекций:** `Найти`, `Строка`, `Число`, `Дата`, `Формат`, `Тип`, `ТипЗнч`, `Сред`/`Лев`/`Прав`, `Добавить`/`Удалить`/`Количество`… — процедура/функция с таким именем → **«Ожидается имя процедуры»** (⚠ модуль формы компилируется только при ОТКРЫТИИ формы — на проде);
  - **имя команды формы** = зарезервированное/стандартное (`Найти`, `Обновить`, `Изменить`, `Создать`, `Печать`, `Провести`…) → **«Неверное имя команды элемента формы»** при загрузке `.form` / сборке epf. Свою команду — `<Префикс>_<Имя>`, либо повесить логику на событие элемента (`ПриИзменении` / `OnChange`), а не заводить команду.

### Комментарии
Допустимы только когда:
- Объясняют **почему** (не что) делается
- Описывают сложный алгоритм или бизнес-логику
- Предупреждают о неочевидных побочных эффектах
- Помечают технический долг (TODO, FIXME, HACK)
- Ссылаются на внешнюю документацию или задачу

### Символы в исходнике — только ASCII-пунктуация

- ❌ **Не используй не-ASCII знаки, визуально похожие на ASCII** — ни в комментариях, ни в строковых литералах:
  - тире `—` (em-dash) / `–` (en-dash), минус `−`, неразрывный дефис `‑` → **дефис-минус** `-`;
  - неразрывный пробел (NBSP, U+00A0) → обычный пробел;
  - кириллические `С`/`Р`/`о`/`а` вместо латинских в ключах и идентификаторах.
- BSL Language Server (SonarQube, EDT) флагает их правилом **`InvalidCharacterInFile`** = **MAJOR bug** (роняет reliability-рейтинг). Русское тире `—` в прозе грамматически верно, но в исходнике 1С приоритет у ASCII-дисциплины — линтер требует дефис.
- Проверка перед коммитом: `rg -n "[—–−‑]" src/` (должно быть пусто в комментах/коде; в user-facing строках — осознанно).

### Формирование строковых сообщений

Никогда не передавай конкатенацию строк напрямую в аргумент метода.

```bsl
// ❌ ПЛОХО
ОбщегоНазначения.СообщитьПользователю(
    НСтр("ru = 'Ошибка генерации:'") + Символы.ПС + ТекстОшибки);

// ✅ ХОРОШО
СообщениеОбОшибке = СтрШаблон(
    НСтр("ru = 'Ошибка генерации:%1%2'"),
    Символы.ПС,
    ТекстОшибки);
ОбщегоНазначения.СообщитьПользователю(СообщениеОбОшибке);
```

Выбор инструмента:
- `СтрШаблон` — одноразовое форматирование с переменными
- `СтрСоединить` + массив — накопление строк в цикле (быстрее)
- `+` — допустимо только для двух частей без `НСтр`

## 3. Работа с данными

### Получение реквизитов объектов

❌ **НИКОГДА не используй обращение через точку:**

```bsl
// Загружает весь объект из БД!
ИНН = Контрагент.ИНН;
```

✅ **Используй методы БСП:**

```bsl
// Один реквизит одного объекта
ИНН = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Контрагент, "ИНН");

// Несколько реквизитов одного объекта
РеквизитыКонтрагента = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(
    Контрагент, "ИНН, КПП, ЮридическийАдрес");

// Один реквизит нескольких объектов
ТаблицаИНН = ОбщегоНазначения.ЗначениеРеквизитаОбъектов(
    МассивКонтрагентов, "ИНН");
```

### Работа с регистрами сведений

**КРИТИЧНО:** При записи набора записей ВСЕГДА устанавливай отбор, иначе очистятся ВСЕ записи регистра!

```bsl
// ✅ ПРАВИЛЬНО — с отбором по всем измерениям
НаборЗаписей = РегистрыСведений.ЦеныНоменклатуры.СоздатьНаборЗаписей();
НаборЗаписей.Отбор.Номенклатура.Установить(Номенклатура);
НаборЗаписей.Отбор.ТипЦен.Установить(ТипЦен);
НаборЗаписей.Прочитать();
НаборЗаписей.Очистить();
НоваяЗапись = НаборЗаписей.Добавить();
НоваяЗапись.Номенклатура = Номенклатура;
НоваяЗапись.ТипЦен = ТипЦен;
НоваяЗапись.Цена = 1000;
НаборЗаписей.Записать();

// ✅ Подчиненный регистр — отбор по регистратору
НаборЗаписей.Отбор.Регистратор.Установить(ДокументСсылка);

// ✅ Периодический — отбор по измерениям И периоду
НаборЗаписей.Отбор.Период.Установить(НачалоМесяца(ТекущаяДата()));
```

Чеклист работы с регистрами:
- [ ] Установлен отбор по ВСЕМ измерениям
- [ ] Для подчиненных — отбор по Регистратору
- [ ] Вызван `Прочитать()` перед изменением
- [ ] Использован `Очистить()` для удаления отобранных записей
- [ ] В новых записях заполнены все измерения

Менеджер записи — когда нужна ровно одна запись по ключу:
```bsl
МенеджерЗаписи = РегистрыСведений.НастройкиПользователя.СоздатьМенеджерЗаписи();
МенеджерЗаписи.Пользователь = ТекущийПользователь;
МенеджерЗаписи.Настройка = "ТемаОформления";
МенеджерЗаписи.Прочитать();
Если МенеджерЗаписи.Выбран() Тогда
    МенеджерЗаписи.Значение = "Темная";
Иначе
    МенеджерЗаписи.Значение = "Темная";
КонецЕсли;
МенеджерЗаписи.Записать();
```

### Работа с запросами

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|    Контрагенты.Ссылка КАК Контрагент,
|    Контрагенты.ИНН КАК ИНН
|ИЗ
|    Справочник.Контрагенты КАК Контрагенты
|ГДЕ
|    НЕ Контрагенты.ПометкаУдаления
|    И Контрагенты.ЮридическоеФизическоеЛицо = &ЮрФизЛицо";

Запрос.УстановитьПараметр("ЮрФизЛицо",
    Перечисления.ЮридическоеФизическоеЛицо.ЮридическоеЛицо);

РезультатЗапроса = Запрос.Выполнить();
ВыборкаКонтрагентов = РезультатЗапроса.Выбрать();
```

Правила:
- Всегда используй псевдонимы через `КАК`
- Не выполняй запросы в цикле — используй `В (&МассивКонтрагентов)`
- Условия фильтрации — в `ГДЕ`, не в `ПО`

### Числовые лимиты на сложность запроса

| Метрика | Лимит | Действие при превышении |
|---|---|---|
| Виртуальных таблиц в одном запросе | ≤ 2 | Переписать через временные таблицы (виртуальные дорогие, их планы непредсказуемы) |
| JOIN'ов в одном запросе | ≤ 5 | Разбить на несколько запросов с временными таблицами, либо отправить на ревью (cartesian risk) |
| Подзапросов в `ВЫБРАТЬ` или `ГДЕ` | ≤ 2 | Переписать через JOIN или ВТ |
| Параметров `&XXX` в одном запросе | ≤ 10 | Лишний признак того что запрос делает слишком много |
| Длина текста запроса | ≤ 100 строк BSL-строкового литерала | Разбить на пакет с ВТ |

### Cartesian explosion — обязательная проверка

Каждый `СОЕДИНЕНИЕ` / `LEFT/INNER JOIN` **обязан** иметь условие связи в `ПО` по полям с уникальностью на одной из сторон. Если соединение «всё со всем» — это ошибка, не оптимизация. Признак:

```sql
-- ❌ Картезианский взрыв (нет ПО или ПО по неуникальному)
ИЗ Документы КАК Док
ЛЕВОЕ СОЕДИНЕНИЕ ЦеныНоменклатуры КАК Цены
    ПО Цены.Дата <= Док.Дата  -- неравенство → каждый док умножается на N цен

-- ✅ Корректно — соединение по уникальной паре (Период, Номенклатура)
ИЗ Документы.Реализация.Товары КАК Товары
ЛЕВОЕ СОЕДИНЕНИЕ ЦеныНоменклатуры.СрезПоследних(&Дата) КАК Цены
    ПО Цены.Номенклатура = Товары.Номенклатура
```

При запросе с ≥5 JOIN'ов **обязательно**:
1. Прогнать `ОтладкаЗапросов` или показать план через SQL Profiler.
2. Запросить второе мнение у независимой модели или агента (см. «Повседневный цикл», три контура проверки).

### Кеширование в циклах

```bsl
КешРеквизитов = Новый Соответствие;

Для Каждого СтрокаТаблицы Из ТаблицаДанных Цикл
    ИНН = КешРеквизитов[СтрокаТаблицы.Контрагент];
    Если ИНН = Неопределено Тогда
        ИНН = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(СтрокаТаблицы.Контрагент, "ИНН");
        КешРеквизитов.Вставить(СтрокаТаблицы.Контрагент, ИНН);
    КонецЕсли;
    СтрокаТаблицы.ИНН = ИНН;
КонецЦикла;
```

## 4. Работа с формами

### Директивы компиляции

```bsl
// ✅ ПРЕДПОЧТИТЕЛЬНО — без контекста формы
&НаСервереБезКонтекста
Функция ПолучитьДанныеКонтрагента(Контрагент)

// ⚠️ Только если нужен доступ к реквизитам формы
&НаСервере
Процедура ЗаполнитьДанныеФормы()

// ✅ Универсальный
&НаКлиентеНаСервереБезКонтекста
Функция ФорматироватьСумму(Сумма)
```

### Асинхронность

```bsl
// ✅ Современный подход (платформа 8.3.17+)
&НаКлиенте
Асинх Процедура ВыбратьИЗагрузитьФайлАсинх()
    ОписаниеФайла = Ждать ПоместитьФайлНаСерверАсинх();
    Если ОписаниеФайла <> Неопределено Тогда
        ОбработатьЗагруженныйФайл(ОписаниеФайла);
    КонецЕсли;
КонецПроцедуры
```

### Минимизация переходов клиент-сервер

```bsl
// ❌ НЕПРАВИЛЬНО — 3 обращения к серверу
&НаКлиенте
Процедура ОбработатьДанные()
    Данные1 = ПолучитьДанные1НаСервере();
    Данные2 = ПолучитьДанные2НаСервере();
    СохранитьДанныеНаСервере(Данные1, Данные2);
КонецПроцедуры

// ✅ ПРАВИЛЬНО — 1 обращение
&НаКлиенте
Процедура ОбработатьДанные()
    ПолучитьИСохранитьДанныеНаСервере();
КонецПроцедуры
```

## 5. Транзакции и блокировки

```bsl
НачатьТранзакцию();
Попытка
    Блокировка = Новый БлокировкаДанных;
    ЭлементБлокировки = Блокировка.Добавить("Документ.РеализацияТоваровУслуг");
    ЭлементБлокировки.УстановитьЗначение("Ссылка", Документ);
    Блокировка.Заблокировать();

    ДокументОбъект = Документ.ПолучитьОбъект();
    ДокументОбъект.Записать();

    ЗафиксироватьТранзакцию(); // последний оператор в Попытка
Исключение
    ОтменитьТранзакцию();      // первый оператор в Исключение
    ЗаписьЖурналаРегистрации(..., ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
    ВызватьИсключение;         // без параметров (сохраняет стек)
КонецПопытки;
```

Всегда проверяй контекст: `Если НЕ ТранзакцияАктивна() Тогда НачатьТранзакцию(); КонецЕсли;`

## 6. Обработка ошибок

```bsl
Попытка
    РезультатОбмена = ВыполнитьОбменСВнешнейСистемой(Параметры);
    Если НЕ РезультатОбмена.Успех Тогда
        ТекстОшибки = СтрШаблон(
            НСтр("ru = 'Ошибка обмена с внешней системой: %1'"),
            РезультатОбмена.ОписаниеОшибки);
        ЗаписьЖурналаРегистрации(
            НСтр("ru = 'Интеграция.Обмен данными'"),
            УровеньЖурналаРегистрации.Ошибка, , Параметры, ТекстОшибки);
        ОбщегоНазначения.СообщитьПользователю(
            НСтр("ru = 'Не удалось выполнить обмен. Обратитесь к администратору.'"));
        Возврат;
    КонецЕсли;
Исключение
    ИнформацияОбОшибке = ИнформацияОбОшибке();
    ЗаписьЖурналаРегистрации(...,
        ОбработкаОшибок.ПодробноеПредставлениеОшибки(ИнформацияОбОшибке));
    ВызватьИсключение СтрШаблон(
        НСтр("ru = 'Критическая ошибка обмена: %1'"),
        ОбработкаОшибок.КраткоеПредставлениеОшибки(ИнформацияОбОшибке));
КонецПопытки;
```

Устаревшие глобальные функции (не использовать с 8.3.17+):
- ❌ `ПодробноеПредставлениеОшибки()` → ✅ `ОбработкаОшибок.ПодробноеПредставлениеОшибки()`
- ❌ `КраткоеПредставлениеОшибки()` → ✅ `ОбработкаОшибок.КраткоеПредставлениеОшибки()`

## 8. Именование

### Переменные

```bsl
// ✅ Существительное, PascalCase, полные слова
Контрагент = ...;
СписокКонтрагентов = ...;
ВыборкаДетальныхЗаписей = ...;

// ❌ Запрещено
МассивКонтрагентов = ...; // венгерская нотация
СоотСоответствие = ...;   // венгерская нотация
СтрСтрока = ...;          // венгерская нотация
Сумма_НДС = ...;          // подчёркивание для разделения слов
ДопПараметры = ...;       // сокращения вместо полных слов
```

### Процедуры и функции

```bsl
// ✅ Процедуры — от глагола
Процедура ЗаполнитьДанныеКонтрагента()
Процедура СоздатьФайлОтчета()

// ✅ Функции — от описания результата
Функция ПолучитьСуммуДокумента()
Функция НайтиПоИмени()

// ✅ Проверки — "Это" или причастие
Функция ПроверитьКорректностьИНН()
Функция ЕстьПравоНаИзменение()
```

### Прочее
- Булевы — как утверждение: `ЕстьОшибки`, `ЭтоТоварТара`
- Максимум **7** параметров метода, **3** необязательных
- Максимум **4 уровня** вложенности — используй ранний возврат

### Ранний возврат (Guard clauses)

```bsl
// ✅ ПРАВИЛЬНО
Если НЕ ЗначениеЗаполнено(Контрагент) Тогда
    Возврат;
КонецЕсли;
```
