# Стандарты разработки 1С: Обычные формы (обычное приложение)

> **Подключаемый справочник** набора практик: в обязательное ядро не входит.
> Агент читает его по указанию человека или при работе с задачами этого класса.

> Источники: v8std.ru (стандарты 500-528, 417, 441-456, 630-647), CodeStyle1C (GitHub)
> Применимость: 1С:Предприятие 8.1, 8.2 обычное приложение, legacy-конфигурации

---

## 1. Отличия от управляемых форм

| Аспект | Обычные формы | Управляемые формы |
|---|---|---|
| Клиент-серверное разделение | Нет, всё на клиенте (толстый клиент) | &НаКлиенте / &НаСервере |
| Модальные вызовы | Допустимы (Вопрос, Предупреждение) | Запрещены |
| Доступ к элементам | ЭлементыФормы.ИмяЭлемента | Элементы.ИмяЭлемента |
| Размеры формы | Фиксированные, в пикселях | Адаптивные (авторазмер) |
| Компоновка | Ручная (привязки, отступы) | Группы авторазмещения |
| Разделители | Явные элементы-разделители | Нет (автоматически) |
| Закладки | Панели с закладками | Страницы формы |
| Меню/интерфейсы | Переключаемые интерфейсы (Общий, Полный) | Командный интерфейс |
| Видимость страниц | Порядок важен: сначала показать, потом скрыть | Порядок не важен |

## 2. Интерфейсы

### Общие правила (std/500)
- Структура по рабочим местам, не по типам объектов
- Максимум 7 элементов в одной группе меню
- Обязательные интерфейсы: **Общий** и **Полный**

### Интерфейс «Общий» (std/501)
- Обязателен, не переключаемый
- Верхний уровень: «Файл» слева, «Сервис/Окна/Справка» справа
- Подменю «Переключить интерфейс» со списком переключаемых

### Интерфейс «Полный» (std/502)
- Группы по функциональным областям (Зарплата, Бухгалтерия, Производство)
- Подменю «Операции» обязательно
- **Запрещено** группировать по типам объектов (Справочники, Документы, Отчеты)

## 3. Формы

### Размеры (std/505)
- Расчёт для разрешения 1280x768
- Максимум: ширина **1256** точек, высота **580** точек
- Закладки должны полностью умещаться

### Отступы (std/510)
- Форма: **8px** от краёв (33px при наличии командной панели)
- Панели: **6px** от краёв

### Привязки (std/509)
- Минимизировать ручную установку
- **Растягиваются**: поля ввода, табличные поля, списки, командные панели, HTML, диаграммы
- **Не растягиваются**: надписи, флажки, переключатели, кнопки, поля фиксированной длины

### Закладки (std/511)
- **Запрещено** несколько страниц у самой формы
- У панелей — не более 5 одновременно видимых закладок
- Стандартное расположение — сверху
- Исключения: формы настроек и программно генерируемые страницы

### Разделители (std/515)
- Вертикальные: ширина 6, горизонтальная привязка — НеПривязано
- Горизонтальные: высота 6, вертикальная привязка — НеПривязано
- Рамка — НетРамки (допускается Одинарная в сложных случаях)

### Порядок обхода (std/512)
- Свойство «Автопорядок обхода» обязательно
- Направление: сверху вниз, слева направо
- Группа = один элемент в обходе

### Единственное табличное поле (std/514)
- Обязательна рамка группы с названием данных
- Стиль «Подчеркивание», над командной панелью

### Одинаковые тексты (std/526)
- **Запрещено** размещать элементы с одинаковым текстом
- Проблемы с документацией и коммуникацией

## 4. Элементы управления

### Имена элементов (std/503)
1. Имя совпадает с данными (если данные непустые)
2. Для путей через точку — имя без точек
3. Без данных — тип + пояснение (ПолеВыбораУсловияОтбора)
4. При дублях — цифровой суффикс
5. Имена элементов в ТабличномПоле — имя колонки реквизита

### Кнопки (std/516)
- Минимум **60x19** пикселей
- Надпись в одну строку
- Частотные кнопки — текст + картинка

### Картинки (std/517)
- Только стандартные платформы или из конфигурации
- **Запрещено** из файла
- Размеры: кнопки выбора **9x15**, обычные кнопки **16x16**, командные панели **16x16**
- СвойствоРазмерКартинки = РеальныйРазмер

### Гиперссылки (std/508)
- **Кнопки** — для изменения/обработки данных, необратимых операций, выбора/подбора
- **Гиперссылки** — для навигации к другим формам/страницам

### Подсказки (std/506)
- Обязательны
- Длина не более 8 слов

### Автовыбор/Автоотметка (std/507)
- Если установлен АвтоотметкаНезаполненного → обязателен АвтовыборНезаполненного
- РежимВыбораНезаполненного = ПриНажатииEnter
- Исключение: числовые и календарные поля

### Пояснения в полях ввода (std/527)
- В незаполненных полях показывать значение по умолчанию или трактовку пустого значения

### Колонки (std/504)
- Изменение размера разрешено для ссылочных значений и строк неограниченной длины
- **Запрещено** для дат, чисел, булевых
- Исключение: иерархические колонки

## 5. Стили (std/524)

- Стиль «Основной» для всей конфигурации
- Во всех формах — стиль «Авто»
- Обязательные элементы стиля:
  - Цвета: ТекстИнформационнойНадписи, ТекстПредупреждающейНадписи, ТекстВторостепеннойНадписи, ЦветГиперссылки
  - Шрифт: ШрифтВажнойНадписи

## 6. Программное управление

### Управление формой (std/519)
- Не использовать `ЭтаФорма` без необходимости
- **Запрещено** открывать формы/диалоги в разделе инициализации
- Управление извне — через реквизиты и методы
- **Запрещено** обращаться к элементам формы из других модулей

### Управление видимостью страниц (std/518)
- **Порядок важен**: сначала включить нужные страницы, потом скрыть ненужные
- Нарушение порядка ломает привязки элементов

### ТекущаяСтрока табличного поля (std/523)
- **Запрещено** использовать для получения значений полей
- Правильно: `ТекущиеДанные` или `ДанныеСтроки`
- Для динамических списков — явно добавлять колонки
- Исключение: системные поля (ПометкаУдаления, ЭтоГруппа, Дата)

### Ограничение действий по условию (std/520)
- Кнопка всегда доступна
- Проверка условий — внутри обработчика нажатия
- При невыполнении — сообщение пользователю

### Обращение к ИБ в частых событиях (std/522)
- Минимизировать обращения к базе в:
  - ОбновлениеОтображения
  - ПриВыводеСтроки
  - ПриАктивацииСтроки
- Решения: кеширование, перенос в менее частые обработчики, предварительная загрузка

### Модули форм (std/630)
- Только код для работы этой формы
- **Запрещены** экспортные процедуры/функции (кроме обработчиков оповещений)
- Параметры — через ОткрытьФорму, не через экспортные методы
- Обновление — через Оповестить, не через экспортные процедуры

### Диалог с пользователем (std/417)
- При выходе спрашивать «Завершить работу с программой?»
- Предусмотреть отключение в персональных настройках

## 7. Соглашения при написании кода

> Эти стандарты общие для обычных и управляемых форм

### Структура модуля (std/455)

```
// Заголовок модуля (описание, авторство, дата)

// Раздел описания переменных

// Раздел программного интерфейса (экспортные процедуры)

// Раздел обработчиков событий

// Раздел служебных процедур и функций

// Раздел инициализации
```

Для модулей форм:
```
// Обработчики событий формы
// Обработчики событий элементов шапки
// Обработчики событий табличных частей
// Обработчики команд формы
// Служебные процедуры и функции
```

### Тексты модулей (std/456)
- Код на русском языке
- Без буквы «ё» в коде (допускается в интерфейсных текстах)
- Без неразрывных пробелов
- Один оператор на строку
- Отступ табуляцией (4 символа)
- Длина строки — **120 символов**
- Удалять мёртвый и закомментированный код

### Имена переменных (std/454)
- Из терминов предметной области
- PascalCase (КаждоеСловоСБольшой)
- Без подчёркивания в начале
- Без односимвольных имён (кроме счётчиков цикла)
- Булевы — как утверждение: `ЕстьОшибки`, `ЭтоТоварТара`
- **Полные слова**: ДополнительныеПараметры, не ДопПараметры

### Имена процедур и функций (std/647)
- Процедуры — от глагола: `ЗагрузитьКонтрагента`, `ПроверитьЗаполнение`
- Функции — от описания результата: `ПолучитьСписок`, `НайтиПоИмени`
- Создание объектов — префикс «Новый»: `НовыйОписаниеОповещения`
- Проверки — «Это» или причастие: `ЭтоДокумент`, `Заблокирован`

### Описание процедур и функций (std/453)
- Обязательно для экспортных
- Секции: описание, параметры, возвращаемое значение, пример
- Для массивов — указывать тип элементов
- Для структур — ссылка на функцию-конструктор

### Общие требования к конструкциям языка (std/441)
- Ключевые слова каноническим регистром
- Не сравнивать булевы с `Истина` / `Ложь` (`Если ЕстьОшибки`, не `Если ЕстьОшибки = Истина`)
- Использовать системные наборы: `Символы.ПС`, не `Символ(10)`

### Переменные в модулях (std/639)
- Минимизировать переменные модуля
- Для объектов — `ДополнительныеСвойства` вместо экспортных переменных
- Для форм — реквизиты формы для сохранения между вызовами

## 8. Практики кодирования (CodeStyle1C)

### Транзакции
```bsl
НачатьТранзакцию();
Попытка
    // ... бизнес-логика ...
    ЗафиксироватьТранзакцию();  // последний оператор в Попытка
Исключение
    ОтменитьТранзакцию();       // первый оператор в Исключение
    ЗаписьЖурналаРегистрации(..., ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
    ВызватьИсключение;          // без параметров (сохраняет стек)
КонецПопытки;
```

### Ранний возврат (Guard clauses)
```bsl
// ПРАВИЛЬНО:
Если НЕ ЗначениеЗаполнено(Контрагент) Тогда
    Возврат;
КонецЕсли;
// основная логика...

// НЕПРАВИЛЬНО:
Если ЗначениеЗаполнено(Контрагент) Тогда
    Если ЗначениеЗаполнено(Договор) Тогда
        // вложенная логика...
    КонецЕсли;
КонецЕсли;
```

### Вложенность
- Максимум **4 уровня** вложенности
- Решения: ранний возврат, вынос в отдельные процедуры

### Параметры методов
- Максимум **7** всего
- Максимум **3** необязательных

### Именование
- Венгерская нотация **запрещена**: `пТекущаяДата`, `тзДанные` — неправильно
- Только PascalCase: `ТекущаяДата`, `ТаблицаДанных`
- Справочники во множественном числе: `Контрагенты`, `Номенклатура`
- Документы в единственном: `ПриходныйОрдер`, `РасходнаяНакладная`
- Без подчёркивания для разделения: `СуммаНДС`, не `Сумма_НДС`

### Запросы
- Условия фильтрации — в `ГДЕ`, не в `ПО`
- Текст запроса на следующей строке после `=`
- Для программной модификации — `СтрЗаменить` с заглушками, `(1=1)` для условий

### Повторное использование переменных
- **Запрещено** присваивать переменной значение другого типа
- Одна переменная — одно назначение

### Информативные сообщения об ошибках
1. Что произошло
2. Почему это ошибка
3. Как исправить
4. Простой язык
5. Текущее и желаемое состояние

## 9. Особенности аудита кода обычных форм

При проверке legacy-конфигураций обращать внимание на:

1. **Модальные вызовы** — допустимы, но фиксировать для будущей миграции
2. **Синхронные вызовы** — нет разделения клиент/сервер, всё синхронно
3. **ЭлементыФормы** — прямой доступ, фиксировать для маппинга на Элементы
4. **Глобальные переменные** — часто злоупотребляют, отмечать
5. **ТекущаяСтрока** — частая ошибка использования вместо ТекущиеДанные
6. **Обращения к БД в частых событиях** — ПриВыводеСтроки, ОбновлениеОтображения
7. **Экспорт из модулей форм** — нарушение инкапсуляции
8. **Размеры форм** — жёстко заданные пиксели, не адаптивные
9. **Привязки** — ручные, часто некорректные
10. **Венгерская нотация** — типичный маркер старого кода
