# Постановка задачи и рабочий цикл (ядро)

Цикл всегда один: **анализ → согласование → правка → проверка → приёмка человеком.**

1. Получил задачу — сначала перескажи её своими словами: что делаем, где,
   по какому признаку поймём, что готово; назови класс задачи (справка, правка
   текста, правка кода, полный цикл) и уровень проверки (правило 04.1–04.2).
   Непонятно — спроси, а не догадывайся.
2. «Сначала обсудим» означает: только анализ и варианты. Кода на этом шаге нет.
3. Предлагая решение, дай 2–3 варианта с ценой каждого и рекомендуй один.
4. Не расширяй задачу сам. Нашёл смежную проблему — доложи одной строкой,
   в работу не бери без «да».
5. «Давай / да / делаем» человека относится к **последнему предложенному**
   варианту, а не к тому, что ты додумал после.
6. Итог каждого шага — факт, а не оценка: «сделано X, проверено Y, осталось Z».
   Слово «готово» без списка проверок не употребляется.
