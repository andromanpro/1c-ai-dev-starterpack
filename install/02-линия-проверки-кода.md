# Сценарий 02: линия проверки кода (исполняют агент и человек)

Предусловие: сценарий 00 пройден. EDT не обязателен — линия работает по исходникам.
Теория для человека — `docs/линия-проверки-кода.md`.

Линия не считается установленной, пока не пройден **негативный контроль**:
заведомо проблемный код обязан дать замечания. Зелёный без красного — пустышка.

## Часть 1 (обязательная): BSL Language Server

| № | Кто | Действие | Проверка результата |
|---|---|---|---|
| 1 | Агент | Проверь java: `java -version` (нужна 17+). Нет — предложи человеку поставить (Eclipse Temurin) | версия ≥ 17 |
| 2 | Агент | Скачай свежий `bsl-language-server-*-exec.jar` со страницы выпусков проекта 1c-syntax/bsl-language-server на GitHub — с подтверждения человека | jar на диске |
| 3 | Агент | Пробный анализ модуля стенда: `java -jar <jar> --analyze --srcDir <набор>/стенд/src --reporter console` | анализ завершился без падения |
| 4 | Агент | **Негативный контроль**: в выводе шага 3 есть замечания (в модуле стенда дефекты оставлены намеренно — как минимум пустой блок Исключение анализатор обязан увидеть) | замечаний ≥ 1 — линия жива |

Замечаний на шаге 4 нет — линия НЕ установлена: разберись с версией jar
и параметрами, см. `docs/если-не-получается.md`.

## Часть 2 (по возможности): SonarQube

Развилка из диагностики (сценарий 00, шаг 6):

- **docker есть** — с подтверждения человека: подними SonarQube Community
  (официальный образ), поставь плагин BSL (проект 1c-syntax/sonar-bsl-plugin-community),
  создай проект и токен (человек, в браузере), прогони sonar-scanner по учебному
  проекту. Проверка: замечания видны в интерфейсе Sonar. Негативный контроль —
  тот же учебный модуль.
- **docker нет** — зафиксируй в итогах: «линия Sonar отложена, работаем на BSL LS»;
  это нормальный старт, Sonar добавится позже.

## Часть 3: АПК — только знать, что существует

Автоматизированная проверка конфигураций (АПК) — контроль стандартов 1С по живой
базе; обязательна при подготовке к «1С:Совместимо». В быстрый контур не входит;
что это и когда браться — страница в справочнике (появится в v1.1).

## Итог шага

Сводка человеку: что установлено, версии, где jar/адрес Sonar, вывод негативного
контроля. Запиши команды анализа в файл проекта, чтобы агент запускал их сам
по правилу `rules/04-проверка.md` п. 1.
