# Сценарий 03: линия тестирования (исполняют агент и человек)

Предусловия: сценарии 00–01 пройдены; платформа 1С; **копия** базы вашего
проекта. Шаблон дополнительно требует (проверь и доложи человеку ДО начала):
OneScript и vanessa-runner — их установка описана в README самого шаблона;
для CI — свой исполнитель заданий. Теория — `docs/линия-тестирования.md`.

Линия не считается установленной без **негативного контроля**: намеренно
сломанный тест обязан дать красный прогон.

## Часть 1 (обязательная): модульные тесты YAxUnit

Готовый шаблон контура уже опубликован — `onec-yaxunit-ci-template`
(точный адрес — `docs/справочник-инструментов.md`). Не изобретаем: адаптируем.

| № | Кто | Действие | Проверка результата |
|---|---|---|---|
| 1 | Агент | Склонируй шаблон рядом с проектом — с подтверждения человека | каталог на диске |
| 2 | Агент | Прочитай README шаблона и его `examples/config-reference.md`; составь список значений для подстановки (пути, имя базы) и покажи человеку | человек подтвердил значения |
| 3 | Человек + агент | Подставьте значения по быстрому старту шаблона (6 шагов README); установка расширений в базу — человек | конфигурация заполнена |
| 4 | Агент | Пробный прогон тестов по README шаблона | прогон завершился, результат зелёный |
| 5 | Агент | **Негативный контроль**: с подтверждения человека временно сломай ОДИН названный тест правкой одного условия; прогони — обязан быть красный; восстанови файл командой `git restore <путь к файлу теста>`; прогони — зелёный; покажи `git status` — дерево чистое | красный → восстановление → зелёный, дерево чистое |

Шаг 5 не краснеет — прогон не видит ваши тесты: разберитесь по разделу
Разбор отказов в README шаблона, прежде чем верить любому зелёному.

## Часть 2 (вторая волна): сценарные тесты Vanessa Automation

Vanessa проверяет поведение форм и сценарии пользователя — беритесь за неё,
когда модульная линия уже работает и появились задачи «проверить форму/процесс».
Подробный сценарий установки — в следующей версии набора; ориентир —
официальный проект Vanessa Automation (адрес — в справочнике инструментов).

## Итог шага

Сводка: где живёт контур тестов, команда прогона, вывод негативного контроля.

чтобы агент гонял тесты сам перед каждым «сделано».
