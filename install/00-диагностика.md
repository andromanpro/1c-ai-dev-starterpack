# Сценарий 00: диагностика машины (исполняет агент)

Запускается по команде человека «настрой окружение». Здесь ничего не
устанавливается — только осмотр и план.

Правила безопасности действуют: ничего не менять, только читать; итог —
план установки на подтверждение человека.

## Шаги

| № | Действие агента | Как проверить |
|---|---|---|
| 1 | Определи ОС и разрядность | команда `systeminfo` (Windows) или `uname -a` |
| 2 | Найди установленную платформу 1С | каталоги `C:\Program Files\1cv8\<версия>\bin\` — перечисли версии |
| 3 | Найди EDT | `1cedtcli.bat -help` в PATH или каталог `C:\Program Files\1C\1CE\` — версия |
| 4 | Проверь git | `git --version` |
| 5 | Проверь python | `py -3 --version` (Windows) или `python3 --version` |
| 6 | Проверь docker (нужен только для SonarQube) | `docker --version`; нет — не ошибка, пометь «линия Sonar будет без docker» |
| 7 | Проверь свободное место на диске под базы и EDT | не меньше 20 ГБ |

## Итог шага (обязателен)

Выведи человеку таблицу «есть / нет / версия» по пунктам 1–7 и план:
что будет ставиться в сценариях 01–03, что уже есть и пропускается,
где потребуется участие человека (установщики, лицензии, права
администратора). **Дождись явного «да» перед переходом к сценарию 01.**

## Стоп-условия

- Нет прав на чтение системных каталогов — остановись, сообщи.
- Платформа 1С не найдена вообще — сообщи: её установка (дистрибутив с портала
  1С по подписке ИТС) целиком на человеке; без неё смысла продолжать нет.
