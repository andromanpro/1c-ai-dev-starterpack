# Сценарий 01: EDT + codepilot1c (исполняют агент и человек)

Предусловие: сценарий 00 пройден, человек подтвердил план.
Теория для человека — `docs/контур-разработки.md` (что именно мы ставим и зачем).

## Шаги

| № | Кто | Действие | Проверка результата |
|---|---|---|---|
| 1 | Человек | Установить 1С:EDT версии 2025.2 или новее (установщик с портала 1С, нужен логин ИТС) | Агент: EDT запускается, версия ≥ 2025.2 |
| 2 | Человек | Создать рабочую область EDT и импортировать проект (или создать учебный) | Агент: каталог рабочей области существует |
| 3 | Агент | Скачать архив выпуска codepilot1c со страницы выпусков форка (точный адрес — `docs/справочник-инструментов.md`) в каталог `_downloads/` — с подтверждения человека, назвав версию выпуска | Файл `com.codepilot1c.update-*.zip` в `_downloads/`, версия совпадает с выбранным выпуском |
| 4 | Человек | Установить плагин: EDT → Help → Install New Software → Add → Archive → выбрать zip → перезапуск EDT | Агент: п. 6 |
| 5 | Агент | Подключить MCP-сервер codepilot к агентской среде: для Claude Code — добавить сервер в конфигурацию MCP; для Codex — блок в config.toml. Фрагменты — в приложении ниже. Показать правку человеку до применения | Конфигурация содержит адрес сервера codepilot |
| 6 | Агент | Пробный вызов: получить список проектов рабочей области через MCP | Список возвращается без ошибок — контур жив |

## Приложение: фрагменты подключения MCP

Claude Code (`.mcp.json` проекта или конфигурация пользователя):

```json
{
  "mcpServers": {
    "codepilot1c": {
      "type": "http",
      "url": "http://localhost:8766/mcp"
    }
  }
}
```

Codex CLI (`~/.codex/config.toml`; синтаксис сверьте с документацией вашей
версии Codex — поддержка HTTP-серверов менялась между версиями):

```toml
[mcp_servers.codepilot1c]
url = "http://localhost:8766/mcp"
```

Порт по умолчанию — 8766; фактический порт и токен, если включён, смотрите
в настройках плагина внутри EDT (страница настроек codepilot). Порт и версию
привязывайте к установленному выпуску — они указаны в его заметках.

## Стоп-условия

- EDT старше 2025.2 — остановись: совместимость плагина не гарантируется,
  спроси человека, обновляем ли EDT.
- Пробный вызов (шаг 6) падает — не изобретай обходов: открой
  `docs/если-не-получается.md`, раздел «MCP не подключился», и пройди по нему.
- Любая правка чужих конфигурационных файлов — только после показа человеку.
