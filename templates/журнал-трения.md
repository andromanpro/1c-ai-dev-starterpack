## Эпизоды

Формат — одна запись на столкновение с правилом. Факты, не мнения.

```
### ГГГГ-ММ-ДД — правило NN.N — краткий заголовок
- Задача: что делали (одной строкой).
- Что произошло: как сработало правило, дословно по действию.
- Цена: что это стоило — время, лишние шаги, ложная тревога, отказ.
```

## Предложения (появляются при ≥2 эпизодах на правило)

Формат предложения — по одному правилу за раз:

```
### Правило NN.N — [ослабляет-защиту, если применимо]
- Эпизоды-основания: даты из раздела выше (минимум два, разные сессии/задачи).
- Сейчас: дословная действующая формулировка.
- Предлагается: новая формулировка.
- Что изменится: одной строкой, включая чем рискуем.
- Решение человека: ПРИНЯТО / ОТКЛОНЕНО / — (дата)
```
