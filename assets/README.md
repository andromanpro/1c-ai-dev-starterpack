# Изображения и происхождение

## Обложка

[iiskra-hero.png](iiskra-hero.png) сгенерирована 09.11.2026 встроенным инструментом
создания изображений. Концептуальный инженерный верстак связывает код, структуру
и проверку. Точный исходный запрос сохранён в [hero-prompt.txt](hero-prompt.txt).

## Снимки отчётов

- [Стенд](stand-check.png), исходный вывод [JSON](stand-check.json).
- [Упаковка и публикация](editions-check.png), исходный вывод [JSON](editions-check.json).

Это снимки HTML-отчётов реальных запусков Python, сделанные Chromium в фоновом
режиме. В отчёт перенесены команда, полный stdout/stderr и фактический код выхода.
JSON содержит версию Python, базовую ревизию и SHA256 проверяемых исходников.
Код 1 у дефектного учебного модуля ожидается сценарием проверки.

Проверка стенда использует текстовую эвристику и встроенный минимальный эталон.
Результаты относятся к контрольным точкам набора. Живую работу 1С и внешних
интеграций проверяют отдельно на разрешённой копии.
