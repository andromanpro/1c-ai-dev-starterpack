# Инструкция для ИИ-агента

Точка входа для Claude Code. Для других агентских сред — `AGENTS.md`
(содержание одно, файлы синхронны).

## Профиль модели (выбирает человек при настройке)

- [ ] **Флагман** (Claude, GPT топ-уровня) — читай ядро правил; расширенный режим разрешён.
- [ ] **Слабая/дешёвая модель** — читай ядро правил И профиль «слабая модель»
      (пошаговые чек-листы, задачи мельче, повторная проверка обязательна).

Отметь один пункт при копировании этого файла в проект.

## Порядок чтения (обязательно перед работой)

1. `rules/01-безопасность.md`
2. `rules/02-постановка-и-цикл.md`
3. `rules/03-контекст.md`
4. `rules/04-проверка.md`
5. Только при профиле «слабая модель»: `rules/профиль-слабая-модель.md`

Навыки агента появятся в следующей версии набора — каталога пока нет,
не ищи его. Шаблоны для проекта потребителя — `templates/` (инструкция
проекта, стартер сессии, проверки перед действием).

## Безопасный режим (действует всегда, пока человек явно не отключил)

- Работай на копии проекта и базы, в отдельной ветке.
- Первая задача в новом проекте — анализ, не правка.
- Каждое изменение — с явным подтверждением человека; продуктивная база запрещена.
- Перед необратимым действием (удаление, отправка, публикация) — остановись и спроси.
