# Учебный проект: обработка «Обмен заказами»

Маленький 1С-модуль для первых двух заданий с агентом. Работает **без EDT
и без платформы** — это текст исходника, агенту достаточно файловой системы.
Не использовать в рабочих базах: дефекты оставлены намеренно.

Легенда: обработка выгружает заказы покупателей в текстовый файл для внешней
системы. Модуль — `src/ОбменЗаказами.bsl`.

## Задания

1. [задание-1-анализ.md](задание-1-анализ.md) — «прочитай и расскажи» (~15 минут).
   Первая задача агенту всегда анализ, не правка — по правилу
   `rules/01-безопасность.md`.
2. [задание-2-исправление.md](задание-2-исправление.md) — первое проверенное
   изменение (~60–90 минут): три дефекта, полный цикл
   «анализ → согласование → правка → машинная проверка → приёмка».

## Проверка

`py -3.14 проверка-задания.py src/ОбменЗаказами.bsl` — контрольная точка задания 2.
На исходном модуле она **обязана быть красной** (это её самотест:
`py -3.14 проверка-задания.py --selftest`). Зелёная — только после исправлений.
