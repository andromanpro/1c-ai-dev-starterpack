# Стенд: приёмка вашего контура

Маленький 1С-модуль, на котором вы **принимаете в эксплуатацию** свою связку
«агент + правила + машинная проверка». Это не упражнения и не курс — это
приёмо-сдаточные испытания вашего рабочего места, как приёмка любой поставки:
пока прогоны не пройдены, контуру верить рано.

Работает без EDT и без платформы — агенту достаточно файловой системы.
Модуль — `src/ОбменЗаказами.bsl` (выгрузка заказов в файл для внешней системы);
дефекты в нём оставлены намеренно, в рабочие базы не тащить.

## Приёмочные прогоны

1. [приемка-1-анализ.md](приемка-1-анализ.md) (~15 минут) — агент читает правила,
   анализирует код и **не лезет править**. Проверяете поведение агента.
2. [приемка-2-цикл.md](приемка-2-цикл.md) (~60–90 минут) — полный рабочий цикл
   «анализ → согласование → правка → машинная проверка → приёмка». Проверяете,
   что цикл и контрольная точка работают у вас, а не в чужих рассказах.

## Контрольная точка

`py -3.14 проверка-стенда.py src/ОбменЗаказами.bsl` — машинная проверка прогона 2.
На исходном модуле она **обязана быть красной** (её самотест:
`py -3.14 проверка-стенда.py --selftest`). Зелёной становится только после
исправлений. Это первый шлагбаум, который вы видите в работе, — дальше они
будут везде.
