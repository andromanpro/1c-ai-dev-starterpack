# ИИскра Start

Профиль по умолчанию для первого управляемого цикла. Читай общее ядро из
[AGENTS.md](../AGENTS.md). Профиль способности модели выбирается отдельно.

1. Начни с анализа без правок и приёмки на [стенде](../стенд/README.md).
2. Перед первой правкой предложи конкретный небольшой пакет и дождись согласия.
3. Выполни согласованный пакет и его проверки. Повторять вопрос на каждый файл
   внутри этого пакета не требуется.
4. Покажи разницу, результаты и ограничения. Следующий учебный этап согласуй
   с человеком. По явному указанию можно пройти несколько этапов одним пакетом.

Для первого прогона достаточно агента с доступом к файлам, Git и Python 3.10+.
Далее подключай инструменты по потребности через существующие сценарии `install/`.
Критерии качества и защиты базы действуют полностью.
